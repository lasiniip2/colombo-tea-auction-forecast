How the forecast works

Match a tea group across consecutive recorded sales. Use seven tea descriptors, the upcoming auction month, and the last published midpoint to estimate the price change. Add that change to the last midpoint for the forecast.

Models were trained on earlier sales and compared on {{ metadata.test_auctions }} later auctions. The CSV records auction dates without publication timestamps, so the backtest assumes the previous report was available before the next sale.

Ensemble methods

Bagging
Random Forest averages trees trained on bootstrap samples.
Randomized trees
Extra Trees averages trees with more randomized split thresholds.
Boosting
XGBoost, CatBoost, and LightGBM build trees in sequence to improve earlier predictions.
Stacking
Ridge regression combines Random Forest and XGBoost using predictions from chronological validation folds.
